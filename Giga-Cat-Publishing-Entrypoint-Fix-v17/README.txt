GIGA CAT Publishing Entrypoint Fix v17

Purpose:
Make Replit Publishing run only the GigaCat website server instead of letting the
monorepo artifact router choose another service.

Install from the existing Replit workspace root:
  unzip -o Giga-Cat-Publishing-Entrypoint-Fix-v17.zip
  bash Giga-Cat-Publishing-Entrypoint-Fix-v17/install.sh

No automatic restart is performed.
