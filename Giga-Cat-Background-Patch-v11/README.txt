GIGA CAT Background Patch v11

What it changes:
- Replaces the current big card background image with the new space / Solana / Giga Cat scene
- Keeps the existing gradient overlay and card layout
- Uses a slightly cleaned-up / sharpened version of the provided image for crisper display

Install:
unzip -o Giga-Cat-Background-Patch-v11.zip && bash Giga-Cat-Background-Patch-v11/install.sh

Restore:
bash Giga-Cat-Background-Patch-v11/restore-latest.sh
