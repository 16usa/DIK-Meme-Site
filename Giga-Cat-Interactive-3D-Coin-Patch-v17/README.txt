GIGA CAT Interactive 3D Coin Patch v17

Purpose
-------
Replace the current round avatar in the existing GIGA CAT buy card with ONE
real, double-sided interactive 3D coin module.

Behavior
--------
- Front and reverse are separate coin faces.
- Cat artwork is integrated into the minted coin face; no extra inscriptions.
- Drag/swipe with a finger to rotate 360 degrees.
- Natural release inertia.
- Slow premium idle rotation after interaction stops.
- Metallic highlight changes as the coin turns.
- Visible physical thickness / gold edge.
- Keyboard: arrows rotate/tilt; Enter or Space flips 180 degrees.
- No external JS libraries or CDN dependency.

Install from the existing Replit workspace root
------------------------------------------------
unzip -o Giga-Cat-Interactive-3D-Coin-Patch-v17.zip
bash Giga-Cat-Interactive-3D-Coin-Patch-v17/install.sh

Rollback
--------
bash Giga-Cat-Interactive-3D-Coin-Patch-v17/restore-latest.sh

Important
---------
The installer DOES NOT restart the server/process.
It does not modify holders logic, server.js, token data, contract data, or links.
